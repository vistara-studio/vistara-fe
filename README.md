# Vistara Backend

<br/>

Frontend for Vistara - A culture and tourism-based digital platform integrating education, ticketing, navigation, and local language translation to preserve and promote Indonesian heritage.

## 🚀 Quick Start

```bash
# Complete setup with test data
npm install

# Development mode
npx expo start or npx expo start --tunnel

```

## 📋 Main Features

### Performance Features
- 🚀 Expo Framework – Optimized development and performance for cross-platform mobile apps
- 🎨 NativeWind – Utility-first styling (Tailwind CSS) for fast and responsive UI
- 📱 React Native Screens – Improves navigation performance by optimizing screen rendering
